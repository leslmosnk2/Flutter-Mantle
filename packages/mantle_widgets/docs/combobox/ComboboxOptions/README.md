# ComboboxOptions

`ComboboxOptions` is a Mantle widget. The theme delegate owns the paint.

Inspired by Mantine [`ComboboxOptions`](https://mantine.dev/core/combobox/).

## Constructors

- `ComboboxOptions(...)` (unnamed / `default`)

## Properties

| Prop | Type | Default |
|---|---|---|
| `children` | `List<Widget>` | required |

## Example

```dart
ComboboxOptions(
  children: const [],
)
```

## Slots

Theme delegates implement:

- `root`
