## 1.1.0

- `@MantleToken` takes a list of size names for context-built scales.
  Static-const palettes use `@MantleToken.consts`.
- `@MantleAppTheme` aggregates same-library token classes into a theme
  with `.of(context)`.

## 1.0.0

- Initial stable release.
- `@MantleToken` and `@MantleComponent` annotations for Mantle code generation.
