# CopyButton

Baseline `CopyButtonDelegate` implementation (`BasicCopyButtonDelegate`).

Mantine-like `CopyButtonDelegate`: copies [CopyButtonContext.value] to the clipboard and exposes `copied` / `copy` to the builder.

Source: `lib/src/widgets/buttons/copy_button.dart`.

`BasicTheme` registers `CopyButtonDelegate: BasicCopyButtonDelegate()`.

Public constructors and props: [CopyButton](/widgets/buttons/CopyButton/).
