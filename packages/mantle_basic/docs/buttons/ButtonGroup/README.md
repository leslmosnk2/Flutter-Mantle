# ButtonGroup

Baseline `ButtonGroupDelegate` implementation (`BasicButtonGroupDelegate`).

Mantine-like `ButtonGroupDelegate`: a tight row or column of buttons. Adjacent border-radius collapsing is a v1 gap; children are laid out with no gap. [ButtonGroupContext.borderWidth] is stored for themes that implement joined borders.

Source: `lib/src/widgets/buttons/button_group.dart`.

`BasicTheme` registers `ButtonGroupDelegate: BasicButtonGroupDelegate()`.

Public constructors and props: [ButtonGroup](/widgets/buttons/ButtonGroup/).
