# Mantle gallery

Live catalog of [`mantle_widgets`](https://pub.dev/packages/mantle_widgets),
painted by [`BasicTheme`](https://pub.dev/packages/mantle_basic).

**Live:** [mantle.leslmosnk.com](https://mantle.leslmosnk.com)

Layout follows [mantine.dev](https://mantine.dev): AppShell chrome, category
navbar, and a page of demos per widget.

```bash
cd packages/mantle_basic/example
flutter run -d linux
flutter run -d chrome
```

Search in the header filters the navbar and the home index. The moon/sun
control toggles `MantleProvider` color scheme.
